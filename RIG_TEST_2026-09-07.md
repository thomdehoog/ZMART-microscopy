## 3. The analysis environments

`ZMART--object_analysis--vision` is gone. There are two now, one per model
plus one for everything classical; the fast detector and the features run
in the classical one, Cellpose in its own:

```
ZMART--object_analysis--classical   scipy, scikit-image, the readers
ZMART--object_analysis--cellpose    torch and Cellpose, the readers
```

Build both from the repo root, in `zmart-microscopy`:

```
python zmart_analysis\workflows\object_analysis\environments\setup_env.py --step classical
python zmart_analysis\workflows\object_analysis\environments\setup_env.py --step cellpose
```

An environment of that name already on the rig is removed first, then
built again:

```
python zmart_analysis\workflows\object_analysis\environments\clean_env.py --step classical
```

Since `56f571b3` both are created from conda-forge and nothing else
(`--override-channels -c conda-forge`); before that the script fell back to
`defaults`. `ZMART--focus--main` is unchanged in content; rebuilt, it also
comes from conda-forge now.

## 4. Build the page and start

```
cd application
npm run build
python zmart-interface.py --built
```

`--built` serves the page as of the last `npm run build`. Without it the
window uses the dev server on 5174 and needs `?bridge=`.
