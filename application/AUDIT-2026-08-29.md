## A. Would break or lie on the Leica

1. **Every scan commands z = 0.** ×2 The plan's positions carry no z;
   `bridge._scan_worker` drives `position.get("z", 0.0)` — an absolute height
   — for every overview and targets position, while the scan step's summary
   says "focus follows the measured map". The scan must place its positions
   through the focus surface. (`bridge.py:575`, `stage.js planOnStage`)
2. **The bridge's configuration readout is mock-shaped.** ×2 `_reading` reads
   `observed["objective"]`/`["serial"]`/`get("pixel_size", {})`; the Leica
   emits `active_objective`/`serial_number`, and `pixel_size` can be `None`
   (parse failure) which the `{}` default does not catch → 500 on
   `/api/setting` and in `_find_targets`. Agree one `observed` key set across
   drivers; `observed.get("pixel_size") or {}` meanwhile. (`bridge.py:250-352,686`)
3. **Invented numbers leave the bridge unmarked**: pixel size defaults to
   1.0 µm (`:343,:686`), camera format to a guessed 512 px (`:236,:328` —
   dead LAS X string-parsing around it), an unreported axis coordinate
   becomes a commanded position in `_drive_to` (`:454`), autofocus family is
   asserted `"software"` for every driver (`:358`). Refuse or mark; never
   substitute.
4. **`IMAGE_TO_STAGE` identity assumption in `detection.py:25`** ×2 — the
   record should carry the driver's real orientation (the Leica has it in
   `orientation.json`); absence should refuse.
5. **Clicking a discovered cell is dead**: `reaches` in
   `discover_targets/layers.js` uses `scale` that exists only inside `paint`
   → ReferenceError. Also: stale `run.gated` ids crash the draw after a
   re-discover — clear `gated` when `cells` rebuilds.
6. **The focus step finishes on a timer, not its promise** — `finish()` sets
   running=null/done *before* `await remeasure()` drives anything; a failed
   map stays marked done; every other live step returns early. Give focus
   the same backend arm. (`main.js:658`)
7. **Seam drift on measureFocus** ×2: the page's `metric` never reaches the
   analysis (always Brenner on live); the bridge echoes `startZ` back so a
   re-run silently starts from the last run's height (the mock strips it);
   `manual` honoured by the mock only. Decide each at one layer; extend
   `backend-contract.js` to every verb, key-by-key, and run it against the
   real bridge.

## C. Races and liabilities (bridge)

14. Check-then-start races on `_focus`/`_scan`/`_targets`; `_records[type]`
    reset can interleave with a draining worker. One dedicated lock.
15. The focus worker holds the instrument lock for the whole map — this is
    the stage-watch 2.5 s timeout seen during every run. Hold per point.
16. `_scan_worker` re-implements `capture_run.capture_positions` (the
    written-twice failure focus_run was created to end). Call it instead.
17. Unguarded record/dict access (`planes[0]`, `x_um: None` from the Leica's
    `driven_to=None`, `KeyError` → `'x'` shown to the operator); query

    engine under running workers; `EXPERIMENT` name hardcoded (take from
    connect); scan progress is last-type-wins (`_the_scan`).

## Verdicts

Pretending: the clean parts are genuinely clean (controller, focus_run,
focus_score, warm, recordings, connection checks); the leaks are at the
joins, and one of them commands the stage. Wiring: right layering, weak
enforcement — everything `backend-contract.js` covers held; everything it
does not has drifted. The three moves that pay most: contract every verb
against the real bridge; make the bridge driver-shaped-by-agreement instead
of mock-shaped; retire the second application.
