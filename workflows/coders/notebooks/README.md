# Notebooks

This is where the workflows for people who write Python will live: notebooks
that drive the microscope through the
[ZMART Controller](https://github.com/ZMB-UZH/ZMART-controller) and run the
analysis pipelines in `../analysis/` with the ZMART analysis engine.

The first to come here are the target-acquisition notebooks: scan an
overview, find the cells or structures of interest, and image each of them
again at higher magnification. They were written against copies of the
controller and drivers that used to live in this repository, and they are
kept in its git history and in the archive branch until they are rewritten on
the installed blocks.

Until then, the same experiment can be run without code in the operator
window: see `../../non-coders/`.
