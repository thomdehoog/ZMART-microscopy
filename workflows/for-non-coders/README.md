# For non-coders

The [ZMART interface](https://github.com/ZMB-UZH/ZMART-interface) lets you scan an overview, find targets, image them again.

1. [Install the interface](https://github.com/ZMB-UZH/ZMART-interface/blob/main/docs/install-on-a-microscope.md).
2. Start it with `zmart-interface`.
3. Pick your microscope and follow the steps.
